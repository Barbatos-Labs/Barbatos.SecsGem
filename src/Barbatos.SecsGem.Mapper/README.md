# Barbatos.SecsGem.Mapper

Convention-over-configuration object mapper for SECS-II: maps C# classes and records to SecsItem trees in both directions using declaration order, with automatic C# to SecsFormat inference, nested lists, custom converters and the optional [SecsMessage] / [SecsItem] / [SecsIgnore] attributes.

> Part of **[Barbatos.SecsGem](https://github.com/Barbatos-Labs/Barbatos.SecsGem)** - a modern, allocation-conscious SECS-II / HSMS-SS / GEM stack
> for .NET 8, 9 and 10.

## Install

```
dotnet add package Barbatos.SecsGem.Mapper
```
