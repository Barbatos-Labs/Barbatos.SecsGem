# Barbatos.SecsGem.Hsms

HSMS-SS (SEMI E37) engine for .NET: an actor-driven connection state machine, a dual-path System.IO.Pipelines decoder with a correctly scoped T8 inter-character timeout, a transaction manager covering T3/T5/T6/T7/T8 over TimeProvider, automatic S9Fx error reporting, and first-class Microsoft.Extensions hosting and dependency injection.

> Part of **[Barbatos.SecsGem](https://github.com/Barbatos-Labs/Barbatos.SecsGem)** - a modern, allocation-conscious SECS-II / HSMS-SS / GEM stack
> for .NET 8, 9 and 10.

## Install

```
dotnet add package Barbatos.SecsGem.Hsms
```
