# Barbatos.SecsGem

Metapackage for Barbatos.SecsGem - installs Barbatos.SecsGem.Core, Barbatos.SecsGem.Hsms and Barbatos.SecsGem.Serialization.Sml in one reference. Ships no assembly of its own.

> Part of **[Barbatos.SecsGem](https://github.com/Barbatos-Labs/Barbatos.SecsGem)** - a modern, allocation-conscious SECS-II / HSMS-SS / GEM stack
> for .NET 8, 9 and 10.

## Install

```
dotnet add package Barbatos.SecsGem
```
